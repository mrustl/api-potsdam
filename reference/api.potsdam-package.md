# api.potsdam: Pushover Notifications for Free Appointments at the API Potsdam

Checks the public online booking calendar (samedi) of the outpatient
clinic of the 'Akademie fuer Psychotherapie und Interventionsforschung'
(API) in Potsdam for free appointments of a given appointment type and
health insurance and sends a 'Pushover' notification as soon as
appointments are available.

## Getting started

- [`check_appointments()`](https://mrustl.github.io/api-potsdam/reference/check_appointments.md):
  check for free appointments and send a Pushover notification (used by
  the scheduled GitHub Actions workflow).

- [`get_free_appointments()`](https://mrustl.github.io/api-potsdam/reference/get_free_appointments.md):
  free appointments as a data frame.

- [`get_event_types()`](https://mrustl.github.io/api-potsdam/reference/get_event_types.md):
  online bookable appointment types ("Terminarten").
